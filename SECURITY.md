# Security Policy

## Supported versions

Only the latest release and `main` receive fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Instead, use GitHub's private
reporting: go to the repository's **Security** tab → **Report a vulnerability**.

Include what you found, how to reproduce it, and the Android version and device you tested on.
You can expect an acknowledgement within a week. Fixes are released first, and details are published
afterwards, crediting you if you wish.

## Scope

In scope: ways another app or person could read or change the block/allow lists or call logs this
app keeps, bypass its screening decisions, or cause it to block calls it shouldn't.

Out of scope: vulnerabilities in Android itself, or in third-party libraries with no impact on this
app (report those upstream).
